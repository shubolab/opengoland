# 下一轮：五个可实际验收的工作包

依据当前 [36 项矩阵](../../reference/acceptance-matrix.json)、[续接快照](README.zh-CN.md)和已有验证记录整理。前三项主要缺完整原生证据，应先复现，再按实际差异修代码。HTTP 环境文件则明确尚未实现。

HTTP 批量、Services、Stop All、原始响应保存已完成本机修正版验证，`.13.3` 双平台安装器已公开并通过独立核验。Mac 本地 SDK 选择、变更块级 Git 提交、Windows owner readiness 旧失败已有对应证据，后续不要再把这些列为缺实现。

| 顺序 | 要回答的日常问题 | 缺口 | 条件 |

| 2 | 真实 Go 工程能否顺畅使用，gopls 异常后能否恢复未保存代码？ | 缺实际容量和崩溃恢复证据 | 固定提交的工程副本 |

## 1. 工程设置与分析结果一致

现有 [模块任务](../../verification/module-task-scopes.md)已覆盖命令目标、外部成员、GOWORK 和 SDK；gopls 也已接入 GOOS、GOARCH、CGO 和 tags。下一步使用两个工作区模块、一个工程目录外的本地 replace 依赖、两个互斥 tag 文件，在 GoLand 和本产品中执行同一序列：修改成员、切换 tag、改变依赖导出符号、保存与重启。

完成标准：工程面板、补全、导航、诊断、原生 Run/Test 与相同 SDK 的 CLI 结果一致。未保存 go.work 的编辑器行为单独记录，不能用运行前 Save All 的结果代替。若缺少方便的成员管理入口，先观察参考端实际交互。

## 2. 真实工程性能与服务恢复

矩阵 ROBUST-02 尚无真实容量测量；[文档同步记录](../../verification/lsp-document-sync.md)只覆盖初始化窗口。选择固定提交、依赖可复现的真实 Go 仓库，两产品使用同一机器和 SDK，明确冷启动、热重开、第一次搜索、跨包导航与内存采样边界。工具等待时间不能当成 IDE 输入 p95。

恢复场景：在自有副本中保留一份未保存的中文/emoji Go 文件，核验身份后仅终止本轮拥有的 gopls，再通过产品实际提供的方式恢复。验证补全、诊断、跳转、Undo 和保存前磁盘哈希，退出后核查 app、engine、gopls 的已知身份。

完成标准：有可重做的原始测量和两端差值；未保存内容不丢失，旧诊断得到替换，进程得到清理。若没有自动恢复能力，明确记录实际恢复入口和差距。

## 3. 实际中文输入法

矩阵 UI-03 已有 UTF-16、emoji 和范围检查，但中文界面、粘贴中文与普通按键不能证明组合输入正常。使用同一输入源，在注释和字符串中实际拼音组词，分别取消、提交候选；在 emoji 前后编辑，在组合输入中使用补全与 Escape，再完成 Rename 和 Undo。

完成标准：记录光标、选区、最终文字、保存字节和诊断；没有重复提交、漏字、半个代理项、光标错位或 Undo 吞掉其他操作。工具无法产生真实组合输入时，保留该条件缺口。

## 4. HTTP 环境文件

[HTTP 范围](../../verification/http-client.md)明确尚无环境文件。先用官方资料和真实 GoLand 确定 `http-client.env.json`、private 文件、查找范围及覆盖优先级，再实现命名环境和 JSON 字符串变量。保留编辑器快照，并使 Run Again 使用当次环境快照。

完成标准：选择 local/test 后，两端 loopback 服务分别收到正确地址、头和原始正文；覆盖关系、未知/循环引用、缺少文件、运行中切换和超限有明确结果。private 值不写入持久历史或日志。脚本、OAuth、响应引用和动态变量另行安排。

## 5. Windows 第一天的完整流程

使用固定版本及哈希的 EXE，在可操作的 Windows 桌面和独立配置中安装。中文包通过本产品现有“安装简体中文语言包…”官方分发入口取得匹配构建，再走原生安装、语言选择及重启；普通兼容插件通过 Marketplace 安装。中文包不是依赖旧 Marketplace 语言包条目。

打开含空格、中文、emoji 的短路径自有 Go 工程，依次完成 Run/Test/Stop、外部 SDK 选择与恢复、PowerShell 的 cwd/SDK 环境/Tab 多候选/Ctrl-C、本地 Git Diff 与提交、项目关闭及退出清理。

完成标准：EXE 用户能重复整条操作链；插件实际启用、字节及目标进程身份有证据。CI owner 的 8 项测试和安装启动 smoke 已通过，但不代替这条桌面操作链。远程凭据测试使用明确可用的测试远端，单独记录。

## 另需外部条件的调试

本机 Developer Mode 仍禁用。获得该条件后，再补同版本 GoLand / open Goland 的 Test Debug、断点与变量、失败重跑、准备中 Cancel 和退出清理。现有“Stop 后迟到暂停通知”警告应按会话状态单独调查；已有记录说明目标与测试进程已结束，不能直接写成进程泄漏。

这些工作包没有关闭整个 36 × 2 矩阵，也不构成完整 GoLand 已完成的声明。下一轮按实际失败和日常使用影响继续推进。
