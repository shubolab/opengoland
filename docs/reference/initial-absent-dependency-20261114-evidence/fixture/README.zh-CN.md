# 本轮夹具的原字节

`app/` 是本轮调用方的三个原始文件，摘要与启动记录一致。原依赖路径为 `app/../dep`，首次打开工程时不存在；本目录也不提供名为 `dep` 的已存在目录。

`retained-created-dep/` 是退出时移出的真实目录，inode 90698594，对应最后的 **Message 阶段**，不是首次 Greeting 阶段。原 Greeting 版本后来被覆盖，只有操作记录中的 SHA，不能把这里的 Message 源码冒充当时原文件。所有源文件保持原字节，无自动恢复/模拟代码。

这些文件用于说明和后续单独复现；仅下载本夹具不等于执行过 IDE 验收，也没有已经验证的重开或 Reload 绕过方法。
